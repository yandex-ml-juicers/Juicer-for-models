# Server: как ставить эксперименты на сервере

Гайд для подключения к серверу и возможности работать удаленно через VS code

## Установка плагина для VS code и подключение к серверу в первый раз

1. В VS code заходим во вкалдку `Extensions`, в поиске вбиваем `Remote - SSH` и устанавливаем
2. Нажимаем `Ctrl+Shift+P` и вбиваем `Remote - SSH: Open SSH Configuration file...`, нажимаем. Далее выбираем путь вида `...\\.ssh\config`
3. В открывшимся файле удаляем все и вставляем
    ```
    Host mla-server
        HostName SERVER_IP
        User USERNAME
        IdentityFile C:/Users/retro/.ssh/id_ed25519
        IdentitiesOnly yes
    ```
    Где заменяем `SERVER_IP` и `USERNAME` на необходимые (В чате с сережей прикреплена фотография)
    И `IdentifyFile` заменяем на путь к вашему приватному ssh ключу
4. После сохранения и закрытия файла еще раз нажимаем `Ctrl+Shift+P` и вбиваем `Remote-SSH: Connect to Host`, после чего выбираем `mla-server` или другое название, если вы его меняли
5. Откроется новая вкладка VS code, нужно будет выбрать `Linux`
6. После чего VS code попросит ввести секретную фразу к ключу, если вы ее добавляли то вводите, если отсутствует, то оставьте нетронутым поле. После нажмите `Enter`

## Повторное подключение к серверу
1. Теперь достаточно просто зайти в VS code и нажав `Ctrl+Shift+P` выбрать `Remote-SSH: Connect to Host`
2. Откроется новая вкладка VS code, нужно будет выбрать `Linux`
3. После чего VS code попросит ввести секретную фразу к ключу, если вы ее добавляли то вводите, если отсутствует, то оставьте нетронутым поле. После нажмите `Enter`

## Работа на сервере
1. Создайте папку для проектов командой ```mkdir -p ~/projects```, название может быть любым другим
2. Перейдите в папку и склонируйте репозиторий. Работайте ровно также как на локальном компьюетере
